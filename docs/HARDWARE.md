# Hardware

Keyboard-emulating SKU scanners can use the POS search field and Enter. This behavior was browser-tested as ordinary product selection, not tested on physical scanners. The receipt opens the browser print dialog via Print receipt. CSS targets an 80 mm content width, but paper margins and driver behavior depend on the printer.

58 mm, A4/A5, direct printer commands, cash drawers, certified card terminals, scales, customer displays, camera scanning, local bridge and Unicode PDF generation are pending. HTML printing is not evidence of physical device compatibility.
